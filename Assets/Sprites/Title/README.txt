初始页标题素材目录（「这也叫地牢?」）
=========================================

推荐做法：把「这也叫地牢」**作为一张整图**生成，命名为下面这个文件放进来即可：

| 用途            | 文件名          |
|-----------------|-----------------|
| 标题整图        | title_main.png  |
| 「?」按钮图标   | char_q.png      |

- `title_main.png`：整张「这也叫地牢」（透明背景 PNG，尺寸随意，代码把高度归一到 80px、宽度按比例）。放进来就整图显示。
- `char_q.png`（可选）：放进来则作为「开始」按钮的「?」图标，替代原来的文字 ?；不放就用文字 ?。

回退规则（都不会崩）：
- 没放 `title_main.png` → 自动回退成 5 个金色描边文字（也可改放逐字图 char_zhe.png / char_ye.png / char_jiao.png / char_di.png / char_lao.png，见下）。
- 逐字图文件名（仅在你想要逐字而非整图时使用）：

  | 字 | 文件名        |
  |----|---------------|
  | 这 | char_zhe.png  |
  | 也 | char_ye.png   |
  | 叫 | char_jiao.png |
  | 地 | char_di.png   |
  | 牢 | char_lao.png  |

贴图要求：
- 透明背景 PNG（游戏背景是暗色，亮色字更醒目）。
- 尺寸随意，代码会按比例缩放。

放好图后，重开游戏（或重启编辑器让 Godot 导入）即生效。
若改了图但没更新，多半是 Godot 没重导 —— 关掉再开一次即可。
