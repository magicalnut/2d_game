【在此处放置本角色的精灵图】
文件名必须为：sheet.png
（游戏进入战斗时会自动按所选角色加载，无需改代码）

==================== 精灵图表布局规范 ====================
尺寸：228 × 300 像素（3 列 × 4 行，每帧 76 × 75）
  列（横向 3 帧）：x = 0, 76, 152
  行（纵向 4 排）：
    第 0 排 (y=0)   → back   朝后（背面行走）
    第 1 排 (y=75)  → left   朝左
    第 2 排 (y=150) → idle   待机
    第 3 排 (y=225) → right  朝右
    toward（正面/朝向玩家）复用 idle 那一排（第 2 排）
每排 3 帧即构成一段 3 帧循环动画。

参照：直接复制流浪者原图
  Assets/Sprites/Heroes/wanderer/sheet.png
的结构，把人物换成你设计的角色即可，保持同样的网格与排布。
