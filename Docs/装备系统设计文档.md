**游戏**：《这也叫地牢》  
**版本**：v1.0 — 适配 Godot 4.7  
**状态**：设计完成 → 待实现

## 1. 设计支柱

| # | 支柱 | 说明 |
|---|------|------|
| 1 | **战斗外决策，战斗内爽** | 装备选择发生在整备页/波次间隙，不能打断割草的核心爽感循环。进图后属性自动生效，无需手动操作。 |
| 2 | **槽位即定位，不堆叠同类** | 6 个槽位各自绑定一种属性主方向；玩家不能堆 6 个攻击装，必须在攻击/防御/辅助/机制之间做权衡。 |
| 3 | **轻量数据，重节奏感** | 不搞复杂词缀、不搞装备背包网格。装备只有「稀有度 + 等级 + 几条固定属性」，玩家 3 秒内看懂一个装备。 |
| 4 | **与波次系统同频** | 装备获取节奏绑定现有波次系统（每 5 波、精英怪、升级抽卡），不另开一套资源循环。 |
| 5 | **降级容错，美术可缺** | 与项目现有风格一致：没图时文字标签 + 色块兜底，有图时自动替换，系统不崩。 |

## 2. 核心数据模型

### 2.1 装备定义（Equipment Definition）

```gdscript
# 单件装备的定义（静态数据，只读）
{
    "id": "rune_of_fire",
    "name": "烈焰符文",
    "slot": "rune",           # 槽位类型，决定能放进哪个格子
    "rarity": 2,              # 1=白 2=绿 3=蓝 4=紫 5=金
    "max_level": 5,           # 该装备可升级到的最高等级
    "base_stats": {           # 1 级时的基础值（具体键见 2.3）
        "atk_bonus": 5,
        "crit_chance": 0.02
    },
    "growth_stats": {         # 每升 1 级增加的值
        "atk_bonus": 3,
        "crit_chance": 0.015
    },
    "flavor": "灼烧敌人的意志。"   # 风味文本，Tooltip 显示
}
```

### 2.2 装备实例（Runtime Instance）

```gdscript
# 运行时存盘/单局携带的数据（动态）
{
    "def_id": "rune_of_fire",
    "level": 3,
    "rarity": 2,
    "uid": "rune_of_fire_3_1620"   # 唯一标识，用于合成去重
}
```

### 2.3 六槽位定位与可用属性键

每个槽位只能携带特定类型的属性，**不允许跨槽位堆叠同一属性**。

| 槽位 | 名称 | 核心定位 | 可用属性键（白字） |
|------|------|----------|-------------------|
| **rune** | 符文 | 攻击/输出 | `atk_bonus`（基础伤害加成）, `crit_chance`（暴击率）, `crit_damage`（暴击伤害倍率）, `projectile_speed`（弹速加成） |
| **pet** | 宠物 | 自动辅助 | `pet_dps`（宠物自动攻击 DPS）, `pet_heal_tick`（宠物周期性回血）, `pet_magnet`（宠物拾取范围） |
| **amulet** | 护符 | 防御/生存 | `max_hp_bonus`（最大 HP 加成）, `def_bonus`（减伤比例）, `regen_per_sec`（每秒回血）, `knockback_resist`（击退抗性） |
| **potion** | 药剂 | 一次性爆发 | `potion_heal`（使用立即回复 HP）, `potion_burst`（使用 5 秒内攻击力×1.5）, `potion_shield`（使用获得 3 秒无敌盾） |
| **token** | 信物 | 技能强化 | `skill_cd_reduction`（技能冷却缩减）, `skill_area_bonus`（技能范围加成）, `skill_duration_bonus`（技能持续时间） |
| **relic** | 圣物 | 特殊机制 | `exp_bonus`（经验获取加成）, `pickup_radius`（拾取范围）, `revive_chance`（死亡时 1 血复活概率）, `kill_heal`（击杀回血） |

> **设计意图**：每个槽位解决一个明确的问题。符文 = 打更快；护符 = 活更久；药剂 = 应急翻盘；信物 = 技能更爽；宠物 = 自动帮忙；圣物 = 发育/机制。玩家必须做取舍，不能无脑堆攻击。

## 3. 稀有度与等级系统

### 3.1 稀有度（5 档）

| 稀有度 | 颜色 | 等级上限 | 基础属性倍率 | 获取难度 |
|--------|------|----------|--------------|----------|
| 1 ★ 普通 | 白/灰 | Lv.3 | ×1.0 | 初始/低级掉落 |
| 2 ★★ 优秀 | 绿 | Lv.5 | ×1.4 | 普通合成/中级掉落 |
| 3 ★★★ 稀有 | 蓝 | Lv.7 | ×2.0 | 精英怪/高级合成 |
| 4 ★★★★ 史诗 | 紫 | Lv.9 | ×2.8 | BOSS 掉落/史诗合成 |
| 5 ★★★★★ 传说 | 金 | Lv.10 | ×4.0 | 高层 BOSS/极低概率 |

### 3.2 等级公式

装备实际属性 = `base_stats × rarity_multiplier + growth_stats × (level - 1)`

**示例**：
- 烈焰符文（绿，Lv.3）
  - `atk_bonus` = `5 × 1.4 + 3 × (3-1)` = `7 + 6` = **13**
  - `crit_chance` = `0.02 × 1.4 + 0.015 × 2` = `0.028 + 0.03` = **5.8%**

### 3.3 合成系统（三合一升星）

```
规则：3 件同槽位 + 同稀有度 + 同 def_id（或同系列）→ 1 件同 def_id 稀有度+1，等级继承最高者

白(3) + 白(3) + 白(3) → 绿(3)
绿(5) + 绿(3) + 绿(3) → 蓝(5)   # 等级继承最高
蓝(7) + 蓝(7) + 蓝(7) → 紫(7)
紫(9) + 紫(9) + 紫(9) → 金(9)   # 传说上限 Lv.10，需再升 1 级
```

> **合成在整备页完成**：点击已有装备的槽位 → 弹出合成面板（显示可合成的组合）→ 确认后消耗旧装备，生成新装备。  
> 同局内不可合成（只可在整备页/局外），避免战斗内打断。

## 5. 装备槽等级与钻石系统（局外解锁）

> **核心设计**：局外"解锁槽位"和"高级装备许可"，局内随机获取装备。玩家花钻石买的是**选择权**，不是直接属性。

### 5.1 槽位等级规则（1-12级）

| 等级 | 解锁内容 | 效果 |
|------|----------|------|
| **1级** | 符文槽 | 可装备 1 件普通装备（白/绿） |
| **2级** | 宠物槽 | 可装备 2 件普通装备 |
| **3级** | 护符槽 | 可装备 3 件普通装备 |
| **4级** | 药剂槽 | 可装备 4 件普通装备 |
| **5级** | 信物槽 | 可装备 5 件普通装备 |
| **6级** | **圣物槽** | **6 槽全解锁，所有普通装备可用** |
| **7级** | — | 过渡级，无新高级位 |
| **8级** | **首个高级位** | 可携带 1 件高级装备（蓝/紫/金） |
| **9级** | — | 过渡级 |
| **10级** | **第二个高级位** | 可携带 2 件高级装备 |
| **11级** | — | 过渡级 |
| **12级** | **第三个高级位** | 可携带 3 件高级装备（上限） |

**装备分级**：
- **普通装备**：白装、绿装（不占用高级位，6槽全开后任意带）
- **高级装备**：蓝装、紫装、金装（每件必须占用 1 个高级位）

> **认知简化**：玩家只需要记住——白绿随便穿，蓝紫金需要"许可"。

### 5.2 钻石获取（每局无尽模式）

```
钻石 = 到达波次 × 10 + 击杀数 × 0.5
```

| 局内表现 | 钻石估算 |
|----------|---------|
| 打到5波，击杀100 | ~100 |
| 打到15波，击杀400 | ~350 |
| 打到30波，击杀1000 | ~800 |

### 5.3 升级消耗（阶梯递增）

| 目标等级 | 所需钻石 | 累计钻石 | 预估局数（按平均350/局） |
|----------|---------|---------|------------------------|
| 1→2 | 100 | 100 | 1局 |
| 2→3 | 200 | 300 | 1局 |
| 3→4 | 400 | 700 | 2局 |
| 4→5 | 800 | 1500 | 4局 |
| 5→6 | 1500 | 3000 | 4局 |
| 6→7 | 2000 | 5000 | 6局 |
| 7→8 | 3000 | 8000 | 9局 |
| 8→9 | 4000 | 12000 | 11局 |
| 9→10 | 6000 | 18000 | 17局 |
| 10→11 | 8000 | 26000 | 23局 |
| 11→12 | 12000 | 38000 | 34局 |
| **总计** | — | **38000** | **约110局** |

**设计理念**：
- **前6级很快**（约10-15局到满槽）：新手体验不被卡，快速感受到"成长"。
- **后6级很慢**（从6到12约需35局）：给老玩家长期目标，但不强迫。
- **总时长约110局**：对一个Roguelike来说合理，不会让人觉得"肝不动"。

### 5.4 局内遇到高级装备但无法携带时的处理

| 情况 | 玩家选项 |
|------|---------|
| 高级装备，且高级位有空 | 直接装备 / 替换已有装备 |
| 高级装备，但高级位已满 | 替换已有高级装备 / 跳过 |
| 高级装备，但槽位等级不足 | **拆解为钻石**（安慰奖，少量钻石）或 **存入库存**（待后续版本） |
| 普通装备，槽位有空 | 直接装备 |
| 普通装备，槽位已满 | 替换已有普通装备 / 跳过 |

**UI表现**：超出当前等级许可的高级装备，卡片上标红色锁图标，明确告诉玩家"这是好东西，回去升级槽位就能带了"。

### 5.5 初始装备（新手保底）

1级玩家出门自带 **2件绑定白装**（符文 + 护符），即使只有1个槽位也能穿2件？不，1级只开符文槽。

**修正**：
- **1级默认开符文 + 护符两个槽**（保证新手有2件装备，不裸奔）
- 2-6级再解锁宠物、药剂、信物、圣物
- 这样1级玩家出门：1件符文 + 1件护符 = 2件白装，有基本攻防

## 6. 获取系统

### 6.1 获取途径（与现有系统绑定）

> **重要变化**：局内获取**不受槽位等级限制**——玩家可以遇到任何稀有度的装备，但能否装备取决于槽位等级。这制造了"看到好东西但带不走"的张力，驱动玩家回去升级。

| 途径 | 触发条件 | 装备稀有度分布 | 备注 |
|------|----------|--------------|------|
| **初始携带** | 角色确认出战时 | 固定白装（符文+护符各1） | 1级玩家也有2件，不裸奔 |
| **每 5 波特殊选择** | 清场后弹出三选一 | 随层数提升：1-10 层→白/绿；11-20→绿/蓝；21+→蓝/紫 | 与现有特殊技能**竞争同一个三选一位**，玩家取舍 |
| **精英怪掉落** | 击杀带光环的精英怪 | 70% 白，25% 绿，5% 蓝 | 精英怪由 WaveManager 按层数概率生成 |
| **BOSS 必掉** | 击杀 BOSS | 50% 蓝，40% 紫，10% 金 | 固定掉落 1 件，槽位随机 |
| **合成升星** | 整备页手动操作 | 继承规则见 3.3 | 局外/局前均可 |

### 6.2 三选一装备选项的 UI 规则

复用现有的 `special_select_ui.gd` 和 `upgrade_ui.gd` 风格：

```
弹窗标题：「选择一件装备」
三张卡片：
  - 左侧：装备图标 + 稀有度边框色 + 装备名
  - 中间：属性列表（2~3 行白字）
  - 右侧：风味文本（小字灰字）
  - 底部：槽位类型标签（如「符文」「护符」）
  - 若槽位等级不足：红色锁标 + "需要槽位等级 X"
```

**选择后的行为**：
- 若该槽位为空且等级足够 → 直接装备
- 若该槽位已有装备 → 弹出确认：「替换 [旧装备] 为 [新装备]？旧装备将放入库存。」
- 若槽位等级不足（高级装备）→ 弹出选项：「拆解为 XX 钻石」或「跳过」

## 7. UI 交互流程（整备页）

### 7.1 现有整备页改造

```
【出战整备页】

顶部：当前槽位等级 Lv.X / 12  +  钻石数量：XXX

        ┌──────────────┐
        │   角色立绘    │
        │   名字/武器   │
        └──────┬───────┘
               │
    ┌──────────┼──────────┐
    │          │          │
 [符文]    [宠物]     [护符]     ← 左侧三槽
    │          │          │
 [药剂]    [信物]     [圣物]     ← 右侧三槽
    │          │          │
    └──────────┼──────────┘
               │
     [无尽模式]  [关卡模式·即将开放]
         [重新选择角色]
```

**槽位状态显示**：
- **已解锁**：正常显示装备图标/空槽边框
- **未解锁**：灰色蒙版 + 锁图标 + "Lv.X 解锁" 文字
- **高级装备**：装备图标外圈额外金色光环（表示占用高级位）

### 7.2 点击槽位后的状态流转

```
状态 A：槽位未解锁
  → 点击 → 弹出提示：「该槽位需要装备槽等级 Lv.X 解锁」
  → 提供快捷跳转：[去升级]（打开槽位等级面板）

状态 B：槽位已解锁，但为空
  → 点击 → 弹出「获取装备」面板
    → 显示 2 件随机该槽位白/绿装（二选一）
    → 选择后装备，关闭面板

状态 C：槽位有装备
  → 点击 → 弹出「装备详情」面板
    → 显示当前装备属性 + 风味文本
    → 底部按钮：[替换] / [卸下] / [合成升星]（条件满足时显示）
    → 若点击「替换」→ 进入状态 B 的获取流程
    → 若点击「卸下」→ 槽位变空，装备进库存
```

## 8. 最小可用版本（MVP）

> **目标**：用最少的代码和数据量，让装备系统"能穿、能生效、能获取、能升级槽位"，跑通完整链路。

### MVP 范围

| 内容 | 是否包含 | 说明 |
|------|----------|------|
| 6 槽位 UI 展示 | ✅ | 复用现有 `_make_slot`，全部显示（未解锁的灰色+锁） |
| 槽位等级显示 | ✅ | 整备页顶部显示当前等级和钻石数 |
| 槽位升级面板 | ✅ | 简单面板：显示下一级解锁内容 + 升级按钮 + 钻石不足置灰 |
| 槽位点击交互 | ✅ | 已解锁槽：点击空槽 → 二选一；点击有装备 → 详情面板 |
| 装备数据库 | ✅ | **只填 6 件**（2 符文 + 2 护符 + 1 药剂 + 1 圣物） |
| 属性生效 | ✅ | 只实现 `atk_bonus` / `max_hp_bonus` / `move_speed` / `pickup_radius` 四条属性 |
| 进战斗生效 | ✅ | player.gd 读取并应用 |

| 合成系统 | ❌ | MVP 不做，留到 v1.1 |
| 宠物/信物复杂机制 | ❌ | 只展示 UI（未解锁状态），不实现宠物 AI 和技能 CD 修改 |
| 药剂使用按钮 | ❌ | 药剂属性作为被动常驻（简化），不设计主动使用 |
| 库存系统 | ❌ | MVP 不做，卸下装备直接丢弃（或简化为只保留最近1件） |

## 9. 数值平衡表（占位符版本）

> 以下数值需在游戏测试中验证，标 `[占位符]` 的表示首次测试前必须调整。

| 属性 | 1 级白装基准 | 1 级绿装基准 | 5 级绿装 | 满级金装 | 设计意图 |
|------|-------------|-------------|---------|---------|----------|
| `atk_bonus` | 4 | 6 | 18 | 60 | 满金装约 = 1.5 把满星武器的加成 |
| `max_hp_bonus` | 15 | 22 | 62 | 200 | 满金装约 = 2 条 HP 升级 |
| `projectile_speed` | +10% | +14% | +26% | +50% | 手感提升，不破坏平衡 |
| `pickup_radius` | +20px | +28px | +52px | +100px | 经验磁铁，降低走位压力 |
| `exp_bonus` | +5% | +7% | +13% | +25% | 发育向，牺牲即时战力 |
| `def_bonus` | +5% | +7% | +13% | +25% | 减伤，对高伤敌人效果明显 |

**全局约束**：
- 6 件满级金装的总 `atk_bonus` 上限应 ≤ 180（约 = 3 条满星武器），避免装备喧宾夺主。
- 总 `max_hp_bonus` 上限 ≤ 600，保证 BOSS 一击仍有威胁感。

## 11. 边界情况与失败状态

| 场景 | 行为 |
|------|------|
| 玩家装备了同一 `def_id` 的装备在多个槽位 | 不允许 — 槽位类型已隔离，但同一槽位内也禁止重复装备（代码校验） |
| 装备属性导致 HP 超过上限 | 当前 HP 被 clamp 到 `max_hp`，不会溢出；卸下装备后当前 HP 不变（不扣血） |
| 战斗中获取装备但槽位已满 | 弹出「替换/取消」选择；取消则装备掉在地上（复用 `pickup.gd` 逻辑，5 秒后自动消失） |
| 稀有度/等级数据异常（如 level > max_level） | `EquipmentManager.get_gear_stats()` 中 `clamp(level, 1, max_level)`，保证不崩溃 |
| 装备数据库中找不到 `def_id` | 返回空属性字典，不报错，日志打印 `push_warning` |
| 合成时 3 件中有一件等级不同 | 等级继承最高者；若最高者已达该稀有度上限，则保持上限 |
| 玩家槽位等级不足，但局内遇到高级装备 | 显示红色锁标，提供「拆解为钻石」选项；不能直接装备 |
| 钻石数为负数（存档篡改等） | `clamp(diamonds, 0, INF)`，并记录 `push_warning` |
| 玩家试图在未解锁槽位放装备 | `can_equip()` 返回 false，UI 层拒绝操作，不报错 |
