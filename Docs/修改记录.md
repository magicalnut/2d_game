## 已完成的修改

### 1. 死亡动画：为每个角色生成专属配色版死亡效果
原角色 sprite sheet 不含死亡帧，因此基于 `Agent/SlimerDeath.png` 为每个角色生成了与其体型、配色匹配的死亡动画：

| 角色 | 输出文件 | 帧尺寸 | 配色 |
|---|---|---|---|
| Agent | `Assets/Sprites/Enemies/Agent/death.png` | 64×64 × 7 帧 | 青色 |
| Armored Person | `Assets/Sprites/Enemies/ArmoredPerson/death.png` | 64×64 × 7 帧 | 钢灰色 |
| Fox | `Assets/Sprites/Enemies/Fox/death.png` | 33×32 × 7 帧 | 橙色 |
| Mario | `Assets/Sprites/Enemies/Mario/death.png` | 62×52 × 7 帧 | 红色 |

实现方式：
- 保留史莱姆死亡动画的形变与明暗节奏。
- 按每个角色的主色调重新着色。
- 缩放至与各角色 walk/idle 帧相同的尺寸，使死亡动画不再突兀放大或错位。

### 2. 场景文件（.tscn）更新
- 四个角色的 `death` 资源引用从 `Agent/SlimerDeath.png` 改为各自文件夹下的 `death.png`。
- 重写了 7 张死亡 AtlasTexture 的 `region`，匹配新的帧尺寸。
- 所有 `death` 动画的 `loop` 从 `1` 改为 `0`（只播放一次）。
- 四个角色保存时的默认动画从 `death` 改为 `idle`，`frame_progress` 重置为 `0.0`。

### 3. 清理冗余资产
- 删除重复的 `Assets/Sprites/Weapons/bullet.tscn`，保留 `Assets/Sprites/Weapons/Bullet/bullet.tscn`。
- 删除三个孤立的史莱姆死亡副本：
  - `Assets/Sprites/Enemies/ArmoredPerson/SlimerDeath.png` 及 `.import`
  - `Assets/Sprites/Enemies/Fox/SlimerDeath.png` 及 `.import`
  - `Assets/Sprites/Enemies/Mario/SlimerDeath.png` 及 `.import`
- `Assets/Sprites/Enemies/Agent/SlimerDeath.png` 作为生成源保留。

## 验证命令（可在 Git Bash 中执行）

```bash

grep -n "death.png" Assets/Sprites/Characters/*/*.tscn

# 确认 death 动画不循环、默认 idle
grep -n '"loop": 0' Assets/Sprites/Characters/*/*.tscn
grep -n 'animation = &"idle"' Assets/Sprites/Characters/*/*.tscn

# 确认只剩 Agent 下有 SlimerDeath 源图
find Assets -name 'SlimerDeath.png*'

# 确认 bullet 只剩一份
find Assets/Sprites/Weapons -name 'bullet.tscn'
```
